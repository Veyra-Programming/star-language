# ⭐ Star Language Plugin for Antigravity

Official Antigravity Plugin for the **Star Programming Language** ecosystem.

## Features

- **Domain Knowledge**: Equips Antigravity with complete grammar, syntax, and standard library knowledge.
- **Flutter Declarative UI**: Guides the agent to write idiomatic Flutter Material 3 widgets in Star without JavaScript.
- **Android & Mobile Hardware**: Provides patterns for `WallpaperManager`, `GoogleBilling`, gyroscope sensors, and haptics.
- **Toolchain Automation**: Orchestrates `star run`, `star check`, `star preview`, and `star build apk`.

## Installation in Antigravity

This plugin is installed at `~/.gemini/config/plugins/star-language/`.
To view or toggle plugins in Antigravity:
1. Open the **Customizations** page in Antigravity.
2. Ensure **Star Programming Language** is enabled.
